# 🕹️ Offline Tic Tac Toe App

An engaging and responsive **Tic Tac Toe** game built using **Java** and **XML** in **Android Studio**, focusing on clean UI/UX and offline functionality. This app features a complete XO logic system, sound effects, custom animations, and supports both light and dark themes.

## 📱 Features

- 🎨 **Custom UI** using:
  - Custom `Drawable` elements for buttons and game layout
  - Defined `styles.xml` for consistent theme across devices
  - Support for **Day/Night mode** using `AppCompatDelegate`
  
- 🎮 **Gameplay Functionality**:
  - Full XO logic with all possible win/tie conditions implemented
  - Uses `ImageButton` for placing `X` and `O` with custom images
  - Tracks and displays **player win points**
  - **Reset** button to start a fresh game instantly

- 🔊 **Sound Effects** using `MediaPlayer`:
  - Click sound for each move
  - Winning sound for victory
  - Tie sound when no player wins

- 💡 **Animations**:
  - Smooth UI transitions
  - Subtle feedback on moves and win/tie conditions
